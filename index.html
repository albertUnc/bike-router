            Strava

            Log in to Strava once and your rides are imported automatically. Strava's login involves a secret key that cannot live in a web page, so it needs a small free helper (a Cloudflare Worker) that you set up once.

            Setup guide (about 10 minutes, once)
            1. Create an app at strava.com/settings/api. Set Authorization Callback Domain to . Note its Client ID and Client Secret.
            2. Deploy the helper by following worker/README.md in the project folder: a free Cloudflare account, paste worker/strava-worker.js, and add your Client ID, Client Secret and this app's address as settings.
            3. Paste the helper's address and the Client ID below, then press Connect.

              What your rides say about

              Loop from your start

              The loop starts and ends at your first stop. You get up to three candidates to compare on the map. Choosing one replaces your current stops with stops along that loop, which you can still drag.

              Each search sends about 8 to 12 routing requests (the free plan has a daily limit).

              Rider profile

              Sustainable power for a ride of h hours is FTP × (1 h value) × h−fade, limited to 50–105 % of FTP.

              Settings

              How do I get a key?
              1. Go to account.heigit.org and sign up (free; email and password).
              2. Confirm your email, log in and open the Dashboard.
              3. Copy your API key (the whole thing, it can be very long). If none is shown, create one there.
              4. Paste it in the box above and press Save.

              If the openrouteservice.org website is down, the Signup and Dashboard links are also on api.heigit.org. The free plan allows 2000 route requests per day and 40 per minute.

              Backup
              Riders, saved routes and settings as one JSON file. The API key is never included.
